09초기화 · 첫 상태

시연을 여러 번 해도 같은 출발에서 다시 시작하는 법과, 모두 처음부터 다시 만드는 법을 봅니다.

차례
  1. 시연 첫 상태로
  2. 기준 시각(AT) 바꾸기
  3. 모두 처음부터 다시
읽는 법 · 파란 칸 화면에 보이는 단추 · 글자(누름) · 노란 칸 직접 칠 글 · 검은 상자 터미널 명령(복사해 붙여 넣기) · 빨간 점선 상자 화면 그림(빨간 테 = 누를 곳) · 확인 필요 아직 정해지지 않은 값

1시연 첫 상태로 터미널 · AgentOps

할 일
  1. 첫 상태 = 새로 띄운 스택 + 문서 04 1 ~ 8번입니다. 시연 자료만 골라 되돌리는 대본은 없으니 3번(모두 처음부터 다시)을 한 뒤 문서 04를 1번부터 다시 합니다
보일 것
kg-init 끝 줄 'KG_INIT ok AT=… FIRST_PACK_TAG=first …' · AgentOps 'V1 · 운영' · 정비자 홈 '진행 중인 알람 없음'
알아 둘 것
정확도(07) 뒤 효율(08)을 하려면 꼭 이 길로 돌아옵니다. 07의 배포 승인이 남아 있으면 08 3번 대본이 멈춥니다.

2기준 시각(AT) 바꾸기 편집기 · 터미널

할 일
  1. .env의 AT=에 시각(형식 2026-11-11T09:00:00+09:00) — 비우면 처음 켤 때의 지금
  2. 그래프 · 앱 시드는 처음 켤 때 AT를 읽으므로 3번(모두 처음부터 다시)으로 새 시각을 적용
알아 둘 것
앱 시드와 그래프가 같은 AT를 써야 시연 이력 날짜가 맞습니다. 그래서 한쪽만 다시 만들지 않고 둘 다 처음부터 만듭니다.

3모두 처음부터 다시 터미널

할 일
  1. 자료(프로젝트 · 기록 · 그래프 · DB)를 모두 지우고 다시 만듦 — 먼저 .env.agentops를 옮김(앞 프로젝트 id가 들어 있음)
mv .env.agentops .env.agentops.old-$(date +%Y%m%d%H%M)   # 앞 프로젝트 연결 줄 옮겨 두기(없으면 오류 글만 나고 괜찮음)
docker compose down -v
docker compose up -d
  1. 앞 자료를 지우지 않고 남기려면(디스크를 더 씀) — 앞 스택은 멈추기만 하고, .env의 COMPOSE_PROJECT_NAME=를 새 이름(예 lmg2)으로 바꾼 뒤 띄웁니다. 새 이름이면 볼륨도 새로 만들어져 같은 첫 상태가 됩니다
mv .env.agentops .env.agentops.old-$(date +%Y%m%d%H%M)   # 위와 같음
docker compose stop                                        # 앞 스택 멈춤(자료는 남음 · 포트가 비게 됨)
# .env 편집: COMPOSE_PROJECT_NAME=lmg2
docker compose up -d
알아 둘 것
뒤에 문서 04를 처음부터 다시 합니다(7번 대본이 .env.agentops를 새로 만듦). 옮긴 파일은 지우지 않아도 됩니다. 자료는 이름 있는 볼륨 13개와 .env.agentops에만 있고, 저장소 폴더에서 컨테이너로 물린 것은 모두 읽기 전용이라 이 두 길로 첫 상태가 됩니다. 남긴 앞 스택을 다시 보려면 그 이름으로 바꾸고 docker compose start(포트가 같으니 지금 스택은 먼저 stop).
