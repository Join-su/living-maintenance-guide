# manual-v3 — 관계표 없는 매뉴얼 MG-MM 3.0

앱이 쓰는 MG-MM 개정 2.0(네 증상군 전체)을 바탕으로, 점검과 조치를 잇는 표 · 문장을 뺀 시험용 버전(관계표 없는 버전)입니다. 점검 ↔ 원인 ↔ 조치 연결은 승인된 정비 이력에서만 나와야 하는지 보려고 만들었습니다.
`kg-test/manual/cooling.md`(가상 공장 냉각 장 한 장)와는 다른 문서입니다.

| 파일 | 무엇 | 시험 입력? |
|---|---|---|
| `MG-MM-3.0-관계없음.md` | 새 매뉴얼(1 공통 규칙 · 2 점검 방법 · 3 조치 방법 · 4 재가동과 마감 · 부록 A ~ H) | 예 — 매뉴얼은 이 파일 하나 |
| `MG-MM-3.0-관계없음.pdf` | **정본** — MG-MM 2.0 PDF와 같은 꼴(표지 · 문서 정보 · 차례 · 읽는 법 · 본문 · 부록 · 판정 기준 모음 · 그림) 44쪽. md가 원천 | 사람 검토용 |
| `번호-대응.csv` | 옛 절 번호 ↔ 새 절 번호(정비 이력이 옛 번호로 적혀 있어서) | 이력 번호 바꾸기에만 — 옛 번호 구조가 점검 ↔ 조치 짝을 담고 있어 지식그래프 입력에는 넣지 않음 |
| `뺀-것.md` | 무엇을 어디서 뺐나 · 옮긴 것 · 더한 것 · 남은 실마리 | 아니요 |
| `pdf/` | 앱 저장소 `scripts/manual_pdf/`(2.0 PDF 도구) 복사본을 새 구조에 맞춰 고친 것 — 원인 코드 꼬리표 0 · 원본 손 0 | 아니요 |

PDF 다시 만들기(설치 0 · 밖 요청 막음): `PW_NODE_MODULES=<앱 저장소>/node_modules kg-test/manual-v3/pdf/make_pdf.sh <빈 작업 폴더 절대 경로>`
